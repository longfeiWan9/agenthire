# D5.6 — Security Boundaries

**Mode:** `STRICTLY_OFFLINE / NO_PROVIDER_NETWORK / NO_SIGNING / NO_PAYMENT / NO_SERVICE_EXECUTION`

## Allowed

- Local browser → local Next.js (`pnpm dev:ui` / `pnpm start`)
- Server routes / RSC / server actions reading **fixed** local evidence paths
- In-memory demo HireJob / approval state in the Node process
- Reuse of offline adapters, jobs, hiring quote/approval modules

## Forbidden

| Surface | Status |
| --- | --- |
| Provider HTTP / DNS / RPC / WebSocket | Forbidden |
| User-supplied provider URL fetch / proxy | Forbidden |
| User-supplied filesystem reads | Forbidden |
| OPENAPI-001 or D4.4b marker reuse/reset | Forbidden |
| Service execution / OpenAPI fetch | Forbidden |
| Facilitators / wallets / signing / payment / chain writes | Forbidden |
| External fonts CDN / analytics / remote scripts | Forbidden |
| Synthetic → verified promotion | Forbidden |
| B4 verification evidence mutation | Forbidden |

## Capability routing

`isSafeCapabilityId` / `assertSafeCapabilityRouteParam` reject path separators, `..`, and URL-shaped ids. Unknown ids → 404.

## Quote & approval

Live quote remains unavailable for QuantJourney (interface undocumented). Synthetic quotes are labeled. `simulationApproved` never sets `executionAuthorization` or `paymentExecutionAuthorization`. Modified binding / replay fail closed. `paidVerified` stays false.

## Dependency posture

Added only `next`, `react`, `react-dom` (+ React type packages) for the App Router UI. No UI kit, no font packages, no analytics SDKs.
