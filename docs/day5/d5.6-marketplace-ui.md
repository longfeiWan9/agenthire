# D5.6 — Marketplace UI & Offline Hiring Vertical Slice

**Mode:** `STRICTLY_OFFLINE / NO_PROVIDER_NETWORK / NO_SIGNING / NO_PAYMENT / NO_SERVICE_EXECUTION`

## Summary

AgentHire ships a local Next.js App Router marketplace explorer over the committed D4.5 capability catalog (690 capabilities · 5 agent profiles · 3 ERC-8004 identities · 4 categories + Other). The QuantJourney SEC Company Identity capability (`cap:79da211975c2`) exposes an offline hire console that reuses D5.2–D5.3 adapters, HireJob, quote preview, and approval session logic. No provider HTTP/DNS/RPC, wallets, signing, payment, or service execution.

## Architecture

- Server-load catalog from `docs/marketplace/evidence/capability-catalog.json`
- RSC pages + small client island (`HireConsole`)
- Server actions in `src/ui/hire-actions.ts` mutate in-memory demo state only
- Domain reuse: `src/marketplace/*`, `src/adapters/*`, `src/jobs/*`, `src/hiring/*`
- Local CSS only — no CDN fonts/analytics/scripts
