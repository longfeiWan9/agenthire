## Rules

2. Display-name equality alone **never** authorizes a merge.  
3. ERC-8004 owner ≠ authenticated operator.  
4. Keep both profile IDs when discussing QuantJourney identity vs skills.  
5. Capability rows stay distinct regardless of profile correlation.
