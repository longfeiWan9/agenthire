# D5.2 — HireJob Offline State Machine

**Mode:** `STRICTLY_OFFLINE / NO_PROVIDER_NETWORK / NO_SIGNING / NO_PAYMENT / NO_EXECUTION`

## States

| State | Meaning |
| --- | --- |
| `draft` | Job created; input not yet validated |
| `inputValidated` | Local tagged-union validation passed |
| `quoteUnavailable` | Live quote blocked (unknown interface and/or unpayable offer) |
| `awaitingApproval` | Waiting for explicit human approval (network still unauthorized) |
| `blocked` | Terminal — policy / authorization block |
| `simulatedSucceeded` | Terminal — offline fixture success (**not** provider return) |
| `simulatedFailed` | Terminal — offline validation or synthetic error |

**Absent by design:** `paidVerified`, `settled`, `liveSucceeded`.

## Flags (always unauthorized in D5.2)

- `approvedForNetworkExecution: false`
- `executionMode: "offlineFixtureOnly"`
- `paidVerified: false`
- `result.providerExecutionVerified: false`

## Transition sketch

```text
draft
  ├─ validateInput (ok)     → inputValidated
  └─ validateInput (fail)   → simulatedFailed

inputValidated
  ├─ markQuoteUnavailable   → quoteUnavailable
  ├─ requestApproval        → awaitingApproval
  └─ block                  → blocked

quoteUnavailable
  ├─ requestApproval        → awaitingApproval
  └─ block                  → blocked

awaitingApproval
  ├─ simulateSuccess        → simulatedSucceeded
  ├─ simulateFailure        → simulatedFailed
  └─ block                  → blocked
```

## Synthetic fixtures

| Fixture | Path |
| --- | --- |
| `success-aapl` | → `simulatedSucceeded` |
| `invalid-input-empty` / `invalid-input-url` | → `simulatedFailed` (local) |
| `provider-error-4xx` / `5xx` | → `simulatedFailed` |
| `incompatible-payment-402` | → `blocked` (`policyIncompatible`) |
| `compatible-payment-unapproved-402` | → `blocked` (`policyCompatibleUnapproved`) |
