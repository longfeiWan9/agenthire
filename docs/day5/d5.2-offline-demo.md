# D5.2 — Offline HireJob Demo

**Mode:** `STRICTLY_OFFLINE / NO_PROVIDER_NETWORK / NO_SIGNING / NO_PAYMENT / NO_EXECUTION`

## Command

```bash
pnpm demo:hirejob:offline
```

Script: `src/scripts/demo-hirejob-offline.ts`  
Package script: `demo:hirejob:offline`

## Behavior

1. Registers the QuantJourney SEC identity draft adapter (`offlineFixtureOnly`).  
2. Resolves it from the registry (registration ≠ live callable).  
3. Assesses QuantJourney identity linkage (`safeToMergeProfiles: false`).  
4. Runs all synthetic HireJob fixtures via `runOfflineHireJobFixtures` / `runOfflineHireJobFixture`.  
5. Prints the mandatory banner on every path:

```text
SIMULATED RESULT — NOT RETURNED BY AN EXTERNAL PROVIDER; NO PAYMENT WAS MADE.
```

6. Exits **nonzero** if any fixture path fails or authorization flags are wrong.

## What it does **not** do

- HTTP/DNS/RPC to providers  
- OpenAPI or agent-card fetch  
- Wallet connect / signing / PAYMENT-SIGNATURE  
- Facilitator contact / settlement  
- Invent QuantJourney method/URL  
- Present simulated payloads as provider returns  
- Set `approvedForNetworkExecution`, `paidVerified`, or `providerExecutionVerified` true

## Success criterion

All seven synthetic fixtures pass offline; banner present; identity merge refused; zero network.
