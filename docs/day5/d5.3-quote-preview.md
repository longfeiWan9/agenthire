# D5.3 — Quote Preview

**Mode:** `STRICTLY_OFFLINE / NO_PROVIDER_NETWORK / NO_SIGNING / NO_PAYMENT / NO_SERVICE_EXECUTION`

## Purpose

Normalize a hiring quote for human review **before** any payment or service execution. Quote preview is not approval and not payment.

## Provenance (never interchangeable)

| Provenance | Meaning |
| --- | --- |
| `advertisedPricing` | Provider advertisement / catalog claim only |
| `observedChallenge` | Captured HTTP 402 Payment Required |
| `syntheticFixture` | Local synthetic 402 fixture (not a provider return) |

## QuoteStatus (parser alone)

`unavailable` · `incomplete` · `parsed` · `policyIncompatible` · `policyCompatibleUnapproved` · `previewReady`

**Excluded** from parser output: `approved`, `paid`, `settled`. Those require separate human approval and (future) payment execution authorization.

## Amount rules

- Atomic amounts are unsigned integer **strings** (BigInt-safe).
- Unknown amount ≠ zero; `amount.unknown=true` when missing/invalid.
- USDC display (`displayUsdc`) uses exactly **6** fractional digits **only** when the asset is confirmed Base Sepolia test USDC `0x036CbD53842c5426634e7929541eC2318f3dCF7e`.

## Controlled payment policy

- x402 v2 · scheme `exact` · network `eip155:84532`
- Asset: Base Sepolia test USDC · decimals **6**
- Reuses `parseHttp402Challenge` + `evaluateOfferPolicy` with `paymentApprovalGranted: false`

## Flags always false in D5.3

- `paymentReady: false` (advertised-only ≠ payment-ready)
- `executionAuthorization: false`
- `paymentExecutionAuthorization: false`
