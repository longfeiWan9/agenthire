# D5.3 — Manual Approval Boundary

**Mode:** `STRICTLY_OFFLINE / NO_SIGNING / NO_PAYMENT / NO_SERVICE_EXECUTION`

## Invariant

**Human approval ≠ execution authorization.**  
`simulationApproved` is a simulated review outcome only. It never grants live network execution or payment construction.

| Flag | D5.3 value |
| --- | --- |
| `executionAuthorization` | **false** (always) |
| `paymentExecutionAuthorization` | **false** (always) |
| `simulationOnly` | **true** (demo approvals) |
| HireJob `paidVerified` | **false** |

## ApprovalState

`notRequested` · `simulationApproved` · `simulationRejected` · `revoked` · `expired` · `blocked`

## Binding fingerprint

Manual approval binds:

- hire job id · capability id · provider key  
- input digest · method · endpoint URL  
- quote id / provenance · offer fingerprint  
- amount · asset · network · recipient · transfer kind  
- freshness expiry · policy version  

Fingerprint = `sha256(canonicalSerialize(binding))` with recursively sorted object keys.

## Fail-closed

| Attack / condition | Result |
| --- | --- |
| Binding field substitution | `blocked` (`substitutionDetected`) |
| Re-approve after `simulationApproved` | fail (`replayDetected`) |
| Revoked / rejected / expired | not approvable |
| `simulationOnly: false` | `liveApprovalForbidden` |
