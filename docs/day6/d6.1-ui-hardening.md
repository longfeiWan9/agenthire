# D6.1 — UI Hardening

**Mode:** `STRICTLY_OFFLINE`  
**Scope:** Fix real defects found in interactive browser QA. No redesign without cause. Hooks remain for future PO UX feedback (`actionFeedback`, trust labels, demo disclaimer).

## Fixes shipped

| Defect | Change |
| --- | --- |
| First-paint hero invisible (`animation: … both`) | `forwards` only; from-opacity 0.92; `prefers-reduced-motion: reduce` disables motion |
| Missing skip navigation | `.skip-link` → `#main-content` on `<main>` |
| Weak focus affordance | Global `:focus-visible` teal ring |
| Action outcomes buried in collapsed notes | `HireSessionSnapshot.actionFeedback` + visible `role="status"` callout; notes open when feedback present |
| Disabled controls looked active | Disabled buttons use muted gray surface + lower opacity |
| Fixture select unlabeled | `<label htmlFor="hire-fixture">` |
| Duplicate React note keys | Index-prefixed keys |
| Footer still D5.6 | Footer → `AgentHire D6.1` |
| Pagination a11y | `rel=prev/next`, `pagination-disabled`, ellipsis `aria-hidden` |
| Category empty state | `role="status"` |
| Hire pending clarity | `aria-busy` on console; `aria-disabled` + titles on gated buttons |
